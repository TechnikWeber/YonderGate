Update source

Defaults to this gateway's own origin / main. Point it at a fork or a branch by entering a git remote name or a full URL (e.g. https://github.com/you/YonderGate.git) — useful for testing your own build on the gateway.

Does what an SSH session would: git pull --ff-only, installs changed dependencies, rebuilds the control app when it changed, then restarts the gateway service — so you can update from a site with nothing but this page. The gateway needs internet for it. If a step fails, it stops there and keeps running the version you have.

System

Shut down parks the SD card and powers the Pi off — the safe way before you disconnect the battery or store the box for the winter, instead of pulling the supply mid-write. It does not come back on its own. On a remote site that means someone has to travel out and power-cycle it, so only do this if you can reach the box or are about to.

Factory reset clears all saved gateway settings (incl. the API secret) — restart to apply defaults.

Site network
Scan is instant; sweep also wakes the quiet ones

Scan reads the kernel's neighbour table — it already knows everything that has spoken recently. Scan + sweep also pings every address in the subnet, which finds the devices that have been silent and takes a few seconds. Both are things you ask for: nothing here runs on its own, and each device's Check button asks that one alone.

Internet for the devices here
Switching it off does not make anything unreachable

Both are on by default. Off means: that interface's devices can still talk to everything local and to your tailnet — you reach them exactly as before — but not to the internet. Useful for a camera that phones home, or a plug that decides to pull firmware over a metered SIM. It is a filter on forwarded traffic by destination, so it survives a switch between LTE and Ethernet and does not touch the setup page or the device proxy. The wired switch does nothing while that interface is the gateway's own uplink — there is nothing behind it to filter. Rules are re-applied at every start, because a firewall rule does not survive a reboot.

A route has to be approved once in the tailnet admin console

Advertising a network lets any device on your tailnet talk to every device here at its real address — no per-device setup, and the gateway turns on IP forwarding for it. But the route has to be approved once (Machines → this gateway → Edit route settings), and until then it exists and carries nothing.

Configuration
Voltage channels
Current channels
What “primary” decides

The channel marked primary is the one the summary line, the charge counting and the alert rules use. With one channel of a kind there is nothing to choose; with several, mark the one that measures the battery — the others stay recorded and graphed.

Temperature channels
Optional — and worth having on a box in a shed

Temperatures are recorded and graphed like the other readings. Give short labels (Battery, Cabinet, Outside) — they are only shown once a kind has more than one channel.

Only the INA228 counts charge in hardware

It integrates charge and energy at ADC rate, so the mAh do not depend on the polling rate or on samples this loop missed — which matters on a box that is meant to run for months. Every other sensor (incl. INA237/238) is integrated on the Pi, and "sensor" then falls back to "pi".

This only changes the percentage, never the mAh

"voltage" and "clamp" need the full & empty voltage above. On a battery that is charged and discharged every day, "voltage" is usually the honest one: coulomb counting drifts unless something tells it when the pack is full.

LTE stick (HiLink)

        
Huawei sticks like the E3372h-320 are their own little router: they dial by themselves and never appear in ModemManager, so the LTE panel above stays empty for them. This reads the stick's own API instead. The interface is found through the routing table, so a LAN on another eth can't be mistaken for it.

Setup hotspot

        

          
          
        

        
        
        

        

          Why the range matters more here than on a home router
          
Tailscale carries the site's real addresses to your tailnet: a camera on 192.168.4.15 here is 192.168.4.15 from your laptop at home. That is what makes the route worth having — and it collapses if the network you are sitting in uses the same range, because then that address is already something on your own desk and the route can never win. Nothing at this end can fix that; the fix is to not collide, which is why the range is a setting. The unusual ones are unusual on purpose. Changing it moves this page: rejoin the hotspot and open the new address.

        

        
        

          
          
          
        

        
The hotspot is open by default so the captive portal can put this page in front of you with nothing to type — set a password (min. 8 characters) once the gateway leaves the bench, and an API secret above if the network isn't yours. Since v1.41.0 it runs in always: it comes up whenever the WiFi radio is free, next to Ethernet or LTE, so you can always reach the gateway. It can never run while the Pi is joined to a WiFi network — one radio can't do both.

        

      


      

        
Security (optional)

        
One shared secret for this gateway. With it set, changing anything — here, and through the device proxy — needs it; this page prompts you once and remembers it for the tab. Reading stays open, so the page always loads and you can never lock yourself out of it. Off by default, because first-time setup should need nothing.

        
Worth setting when the site's network isn't only yours: an open hotspot, a marina or campsite WiFi, a shared LAN. Not needed when the box is reachable only over Tailscale or your own network — a page from the internet is refused either way (see below).

What protects you without a secret: the gateway refuses any request a page somewhere else caused. A website you happen to open — while your phone is on this hotspot — cannot reboot the box or switch a relay through the device proxy, even though it can reach the address. Accepted are requests with no browser behind them (curl, scripts) and pages served from this network, from Tailscale, or by the gateway itself. That is not a substitute for a secret on a network full of strangers: anyone who can open this page can still change things.

Time

        

          
          
        

        

          
          
        

        
        
Time synchronisation is on by default (systemd-timesyncd with the distribution's servers, shown above). A box that boots without internet starts with the wrong time, and every value it records carries that timestamp — that is what the DS3231 (I²C, a few euros) fixes: it keeps time on its own battery through power cuts, the kernel reads it at boot, and once the network is back NTP corrects both. Ticking the box writes the overlay into config.txt for you.

        


        
Mobile data

        

          
          
          
        

        

          
        

        

          
          
        

        

          
          
        

        
The stick's counter is what the carrier sees but resets when the stick reboots; the interface counter works for any uplink but counts local traffic too. Either way the gateway keeps its own total from the differences, so a reset costs nothing. A warning goes out at 80 % — of the monthly allowance, or of the credit once it is billed per megabyte.

        
Prepaid billed per MB has no month: what runs out is the balance, whenever that happens. The counter therefore runs from the last top-up rather than from the 1st, so press I topped it up whenever you put money on the card. On most German tariffs that top-up is also what stops the SIM being deactivated for inactivity — the projection below tells you when the next one is due.

        


        
Traffic per interface

        
…

        

          Where the volume comes from, before you switch anything off
          
Since the last boot, per interface — the counter above is what the month costs, this is which side of the box produced it: the hotspot, the site LAN, or the uplink itself. It counts all traffic on the interface, including what never left the site, so treat it as a comparison between interfaces rather than a bill. The kernel resets these on reboot, which on the default weekly schedule means they cover a week at most.

        


        
Alerts (ntfy)

        
        

          
          
The topic is the password — anyone who knows it can read your alerts and send fake ones. Pick something unguessable, and note that this page only shows it shortened once it is stored.

          
        

        

          
          
        

        
Install the ntfy app, subscribe to a topic name nobody could guess, and put its URL here — anyone who knows the topic can read your alerts. Watched by default: the supply voltage sagging and the data allowance. Add a sensor threshold or a saved device below; each alert waits until the condition has held for a while and then stays quiet for six hours, because a flaky link must not turn into a night of notifications.

Power switches

        
None yet.

        

          
          
          
        

        

          
          
          
        

        

          
          
        

        

          
          

            
          

        

        
        

        
A switch is the only thing here that can act on a device that has stopped answering — everything else can just report it. HTTP plugs (Shelly, Tasmota, any URL) sit next to the device; a relay on the Pi's GPIO needs no network, which matters when the thing to power-cycle is the network. Do not put the gateway itself on a switch it controls.

        


        
        
The software watchdog above assumes this service is still running. If the kernel itself wedges, nothing in user space gets a turn and the box is gone until someone drives there — that is the case this covers.


        
The recovery goes cheapest-first: bring Tailscale up again, then restart the network stack (which redials LTE), and only then reboot. Each step needs its own run of failed probes, so a half-minute outage never gets near a restart. The probe target is an address on purpose — a hostname would make a broken DNS look like a dead link. A box that has just booted will not reboot again inside the same window.

        
And it will not loop: the reboot budget is written to disk, so a restart cannot clear it — at most two reboots a day, six hours apart. When a medium is simply gone (a dead SIM, an unplugged stick, a router that is off), further reboots cannot conjure it back, so the box stops trying and says so instead. The cheaper steps keep running, and a reboot is also skipped while somebody has this page open — a missing uplink does not break local access.

        


      


      

        
Design

        
        

        
        

          The gateway remembers it, not the browser
          
Light is the default — this page is usually opened outdoors, on a phone, at the site. Dark is easier at night and on a screen next to a camera feed. The choice is stored on the gateway, so every phone that opens this page gets the same one; each browser also keeps a copy of the last answer so a cold start does not flash the other palette on its way.
